开始沦为

两次鸦片战争 + 太平天国

英国用炮舰打开国门，《南京条约》使中国开始沦为半殖民地半封建社会；第二次鸦片战争进一步加深危机，沙俄趁机割占北方大片领土；太平天国则从内部动摇清朝统治。

洋务运动 + 甲午战争 + 瓜分狂潮

地主阶级洋务派以“自强”“求富”开启近代化，但甲午战败宣告洋务运动破产；《马关条约》使中国半殖民地化程度大大加深，列强掀起瓜分中国狂潮。

鸦片战争

1840—1842
背景与导火索
根本原因英国打开中国市场
直接原因林则徐虎门销烟
爆发1840年6月
结束1842年8月

19世纪上半期，英国完成工业革命，急需打开中国市场、掠夺原料。中英正当贸易中，中国处于出超地位，英国便向中国大量走私鸦片。 1839年6月3日至25日，林则徐在虎门海滩当众销毁鸦片，虎门销烟是中国人民禁烟斗争的伟大胜利，显示了中华民族反抗外来侵略的坚强意志[reference:0]。

高频易错：虎门销烟是鸦片战争的直接原因（借口），不是根本原因。根本原因是英国为了打开中国市场、倾销商品、掠夺原料。
《南京条约》——中国近代第一个不平等条约
条款内容危害
割地割香港岛给英国破坏领土主权完整
赔款2100万银元加剧财政危机，加重人民负担
通商开放广州、厦门、福州、宁波、上海五处为通商口岸破坏贸易主权，便利外国商品输出
关税英商进出口货物应纳税款，须双方协议中国失去关税自主权

1843年英国又强迫清政府签订《虎门条约》，获取领事裁判权、片面最惠国待遇等；1844年美国、法国分别强迫清政府签订《望厦条约》《黄埔条约》[reference:2]。

影响：鸦片战争改变了中国历史发展的进程。中国丧失了完整独立的主权，自然经济遭到破坏，开始从封建社会变为半殖民地半封建社会。鸦片战争成为中国近代史的开端[reference:3]。

第二次鸦片战争

1856—1860
战争概况
根本目的进一步打开中国市场
主凶英、法
帮凶美、俄
借口“亚罗号事件”“马神甫事件”

英法分别以“亚罗号事件”和“马神甫事件”为借口发动战争。1860年英法联军攻入北京，火烧圆明园，这是人类文明史上的一场浩劫[reference:4]。

主要条约
条约时间核心内容
《天津条约》 1858 外国公使进驻北京；增开汉口、南京等十处通商口岸；外国商船和军舰可在长江各口岸自由航行
《北京条约》 1860 承认《天津条约》继续有效；增开天津为商埠；割九龙司地方一区给英国；增加赔款
沙俄侵占领土 前后共 割占中国东北和西北领土150多万平方千米，是割占中国领土最多的国家；《瑷珲条约》割地最多
高频易错：火烧圆明园的是英法联军，不是八国联军。八国联军侵华发生在1900年，两者相差40年。
影响：中国丧失更多主权，西方侵略势力由东南沿海深入长江中下游地区，俄国侵占北方大片领土，中国半殖民地化程度进一步加深。
3

太平天国运动

1851—1864
兴亡线索
开始1851 金田起义
定都1853 天京
由盛转衰天京事变
失败1864 天京陷落

1851年洪秀全在广西桂平金田村发动武装起义，建号“太平天国”。1853年攻占南京，改名天京，作为都城，与清政府对峙。太平天国后期，天京事变由盛转衰，1864年天京陷落，运动失败。

两个纲领性文件
《天朝田亩制度》

核心是解决土地问题，主张“有田同耕，有饭同食”，反映农民平均分配土地的愿望，但具有空想性，并未实施。

《资政新篇》

洪仁玕提出，是近代中国最早提出发展资本主义的方案，但也未实施，没有引起农民强烈反应。

高频易错：太平天国运动是农民阶级领导的运动，不是资产阶级革命；《资政新篇》虽然带有资本主义色彩，但不能改变太平天国运动的农民战争性质。

历史意义：太平天国运动是中国历史上规模最宏大的一次农民战争，沉重打击了清朝统治和外国侵略势力，但农民阶级的局限性决定了它无法提出科学的革命纲领，最终失败。

洋务运动

19世纪60—90年代
核心信息
领导阶级地主阶级洋务派
口号自强 → 求富
根本目的维护清朝统治
破产标志甲午战争北洋舰队覆没
主要成就
  • 军事工业：安庆内军械所、江南制造总局（国内最大兵工厂）、福州船政局等。
  • 民用工业：轮船招商局、开平煤矿、汉阳铁厂、湖北织布局等。
  • 近代海军：建立北洋、南洋、福建三支海军。
  • 教育：兴办新式学堂（如京师同文馆），派遣留学生出国深造。
如何评价洋务运动
进步性

是中国历史上第一次近代化运动；客观上促进了中国民族资本主义的产生；对外国资本入侵起到一定抵制作用；推动了中国近代教育的发展。

局限性

根本目的是维护清朝封建统治，只学西方技术，不改变封建制度；对西方列强有依赖性；内部腐败，最终没有使中国走上富强道路。

高频易错：洋务运动学习的是西方器物（技术），不是制度；其失败的根本原因是没有变革落后的封建制度，而不是“技术不够先进”[reference:13]。

《马关条约》——大大加深半殖民地化
条款内容关键影响
割地割辽东半岛、台湾全岛及所有附属各岛屿、澎湖列岛给日本严重破坏中国领土主权

高频易错：“允许日本在通商口岸开设工厂”是《马关条约》特有的条款，标志着列强侵华方式从商品输出转向资本输出，这是与《南京条约》最本质的不同之一。
瓜分中国狂潮

《马关条约》签订后，列强掀起瓜分中国的狂潮。三国干涉还辽后，日本向中国索取3000万两白银作为“赎辽费”，列强以此为契机在中国划分势力范围、强租租借地[reference:15]。中华民族危机空前严重。

1895年《马关条约》签订后，康有为、梁启超等发动“公车上书”，揭开变法维新运动的序幕。1898年6月11日，光绪帝颁布“明定国是”诏书，变法开始，9月21日慈禧太后发动政变，变法失败，史称“百日维新”[reference:17]。

主要措施
领域措施
政治裁撤冗官冗员，允许士民上书言事

义和团：“扶清灭洋”

义和团由山东、直隶一带的民间秘密组织发展而来，口号是“扶清灭洋”。这一口号表达了中国人民反对帝国主义的斗争意志，但也具有盲目排外的落后性，同时反映出义和团对清政府的本质认识不清，抱有幻想[reference:20]。

局限性：义和团没有严密的组织形式，没有先进阶级领导，没有科学理论指导，其失败是农民阶级局限性的又一体现。

04 / TRAPS

期中高频易错辨析：这些“坑”一定要绕开

虎门销烟是根本原因还是直接原因？

根本原因 → 直接原因（借口）。英国发动战争的根本原因是打开中国市场，虎门销烟只是导火索。

割香港岛 = 割整个香港？

整个香港 → 香港岛。《南京条约》割的是香港岛；九龙司地方一区是《北京条约》割的；新界是1898年租借的。

火烧圆明园的是八国联军？

八国联军 → 英法联军。火烧圆明园发生在1860年第二次鸦片战争期间，不是1900年八国联军侵华。

《辛丑条约》割地、开通商口岸？

有割地、有通商 → 都没有。《辛丑条约》没有割地、没有开放通商口岸，核心是赔款、禁反帝、划使馆界、驻兵。

洋务运动学的是制度？

制度 → 器物（技术）。洋务派主张“中体西用”，只学西方技术，不改变封建制度；维新派才主张学制度（君主立宪）。

戊戌变法废除了科举制？

废除科举制 → 废除八股文。戊戌变法废除的是八股文，科举制直到1905年才被废除。

《马关条约》和《南京条约》都有开设工厂？

都有 → 只有《马关条约》有。开设工厂是《马关条约》的独有条款，标志着列强侵华从商品输出转向资本输出。

太平天国是资产阶级革命？

资产阶级革命 → 农民阶级运动。太平天国是农民战争，《资政新篇》虽带资本主义色彩，但未改变运动性质。

06 / THREADS

主题线索归纳：各阶层如何回应民族危机

地主阶级 · 洋务派

方案：“自强”“求富”，学习西方器物技术。实践：洋务运动（19世纪60—90年代）。结果：甲午战败，北洋舰队覆没，宣告破产。局限：不改变封建制度，只学技术。

农民阶级 · 太平天国与义和团

太平天国：《天朝田亩制度》《资政新篇》，反封建反侵略，但受农民阶级局限。义和团：“扶清灭洋”，反帝斗争意志强烈，但盲目排外、对清政府抱有幻想。

资产阶级维新派 · 戊戌变法

方案：君主立宪，学习西方政治制度。实践：公车上书→百日维新。结果：慈禧政变，变法失败。意义：在思想文化方面产生了广泛而持久的影响，起到了思想启蒙作用。
